# Hindi Font Generator

A simple and easy-to-use Hindi font generator for creating stylish Devanagari text with different font styles.

## Live Demo

👉 https://hindifontgen.in/

## About

Hindi Font Generator lets you type Hindi or Devanagari text and preview it in different font styles directly in your browser.

You can experiment with different font sizes, text colors, background colors, and font styles to find the look you want for your text.

## Features

- Generate stylish Hindi and Devanagari text
- Preview multiple font styles
- Real-time text preview
- Adjustable font size
- Custom text color
- Custom background color
- Copy text easily
- Download styled text as an image
- Works directly in the browser
- No login required

## How to Use

1. Open the Hindi Font Generator.
2. Enter your Hindi or Devanagari text.
3. Browse the available font styles.
4. Adjust the font size and colors.
5. Copy or download the result.

## Universal header and footer (GitHub Pages)

The shared layout uses GitHub Pages' built-in Jekyll includes, so the header/footer are inserted during the site build. This keeps the navigation and footer in the generated HTML (better for SEO than fetching them after page load).

- Edit `_includes/header.html` once to change the site-wide navigation.
- Edit `_includes/footer.html` once to change the site-wide footer.
- Existing `.html` page names and URLs are preserved.
- Each page has an empty YAML front matter block so GitHub Pages/Jekyll processes the include tags.
- The standalone `404.html` was left unchanged.

Upload the contents of this ZIP to the same repository/branch and replace the existing files. Do not upload the enclosing `hindifontgeneretor-main` folder as a nested folder; upload the files and folders inside it to the repository root. Keep a backup or use a branch before replacing live files.
