What is a Shree Lipi converter?

Shree Lipi is a family of older, non-Unicode Devanagari fonts. It has long been popular for Marathi design and print work, and it is used for Hindi as well. A legacy font like this does not store real Devanagari characters. It stores ordinary character codes and relies on the font to draw each code as a Devanagari shape. That is why the word मराठी is saved as _amR>r and only looks like Marathi once a Shree Lipi font is applied.

A Shree Lipi converter turns normal Unicode text, the kind you type on a phone or a Windows keyboard, into those character codes. It is more than a letter-for-letter swap. The short ि sign has to move in front of its consonant, the reph has to move behind it, and joined letters such as क्ष and ज्ञ are replaced by single ready-made glyphs. The converter above does these steps for you, as you type.

Why Marathi and Hindi design work still uses Shree Lipi

Unicode is the modern standard, and it is what you should use for writing, storing and sharing text. Legacy fonts have stayed in print work for practical reasons:

  • Many print shops, flex banner makers and wedding card designers have templates and old files built in legacy fonts, and they keep working with them.
  • Older design software can display a legacy font even when it cannot shape Unicode Devanagari properly, because the font does the drawing and the software only places characters one after another.
  • Clients usually send text in Unicode, so the designer has to convert it to get the same look in the layout.

The trade-off is real. Shree Lipi text cannot be searched or spell-checked, screen readers cannot read it, it does not work on websites, and it turns into symbols on any computer that does not have the font. Treat it as a design format, not a storage format, and always keep your Unicode original.

Using the converted text in CorelDRAW, Photoshop and other apps

  • CorelDRAW: choose the Text tool, set the font to Shree-Dev-0708, then paste. If CorelDRAW asks how to paste text, pick the option that discards the source formatting and apply the font afterwards.
  • Photoshop: select the Type tool and choose the Shree Lipi font before you paste, so the text is never drawn in a fallback font first.
  • PageMaker or InDesign: paste as plain text, then apply the font to the pasted frame. In InDesign, the paste-without-formatting shortcut does this in one step.
  • Word: set the font first, then paste. If the text shows in another font, select it and apply Shree Lipi again.
  • Phone design apps: apps that let you import your own font file can use Shree Lipi. Import the font, choose it, then paste the copied text.

Before you send a file to a press: the computer at the press may not have the Shree Lipi font. Embed the fonts when you export a PDF, or convert the text to curves or outlines, so the Marathi or Hindi text cannot turn into symbols on their side.

Common problems and quick fixes

  • I see symbols such as _amR>r instead of Marathi: that is the expected result without the font. Install Shree Lipi and select it, or tick the preview box above if it is already installed.
  • The file turns into symbols on another computer: that computer does not have the font. Embed the font in the PDF or convert the text to curves.
  • English words become Devanagari: legacy fonts reuse English character codes. Put English text in a normal font and apply Shree Lipi only to the converted part.
  • A yellow note lists letters under the result: those letters or combinations are not supported yet and were left as typed. Send the word to contact@hindifontgen.in and it can be added.
  • A different Shree Lipi version looks slightly off: this converter is built for Shree-Dev-0708. Check a sample line first if your font is another version.
  • I need to change a word: edit the Unicode text and convert again. Editing converted text by hand is easy to get wrong.

Frequently asked questions

How do I convert Unicode to Shree Lipi?

Type or paste your Marathi or Hindi Unicode text into the box at the top of this page. The Shree Lipi text appears underneath at once. Press Copy, then paste it into your design software after selecting the Shree-Dev-0708 font.

Why does the converted text look like random symbols?

That is normal. Shree Lipi is a legacy font, so the text is stored as ordinary character codes and only looks like Marathi or Hindi when the Shree Lipi font is applied. Install the font and select it, or tick the preview option on this page if the font is already installed on your device.

Which Shree Lipi font does this converter support?

It is built for Shree-Dev-0708 and was checked against sample conversions of that font. Other Shree Lipi versions, such as Shree-Dev-0714, may place a few glyphs differently, so check a sample line before a big print job.

Can I use it as a Marathi to Shree Lipi converter?

Yes. Shree Lipi is mostly used for Marathi, and the converter handles Marathi Unicode text including the letter ळ, the short and long vowel signs, and joined letters such as ज्ञ and श्र.

Does it work as a Unicode to Shree Lipi Hindi converter?

Can I convert Shree Lipi text back to Unicode?

Not on this page. It converts in one direction only, from Unicode to Shree Lipi. Keep your original Unicode text, edit it there, and convert again whenever you need a fresh Shree Lipi version.

Is this Shree Lipi font converter free, and is my text saved?

It is free and needs no signup. The conversion runs in your browser, and the text you type is not sent to or stored on this site's server.

Is the Shree Lipi font itself free?

The font is not included here, and Shree Lipi is usually distributed as part of commercial software. Use a copy you are licensed to use and check its licence terms. This page only converts text.

Why do English words turn into Devanagari after I apply the font?

Legacy fonts reuse the same character codes as English letters. When the Shree Lipi font is applied, English letters are drawn as Devanagari shapes. Keep English words in a normal font and apply Shree Lipi only to the converted Marathi or Hindi text.

Can I use the converted text on a website or in WhatsApp?

Not reliably. Websites and chat apps expect Unicode, so legacy text shows as symbols to anyone without the font. Use Unicode for the web and for messages, and keep Shree Lipi for print and design files.
