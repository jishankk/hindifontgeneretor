Understand the formats

Unicode and Kruti Dev solve different typing needs

Choose the format your document or workplace actually requires, rather than converting every Hindi file by default.

Kruti Dev is an older Hindi font family. It does not store real Hindi letters. Instead, it reuses the normal English keyboard codes and draws a Hindi shape for each one. That is why Kruti Dev text looks like strange English symbols (for example ueLrs) until the Kruti Dev font is applied, and then it turns into नमस्ते.

Unicode is the modern standard. Every Hindi letter has its own code, so text typed on a phone, in WhatsApp, on a website or in Google Docs is Unicode. It can be searched, copied and shown on any device.

Even so, a lot of Hindi work still happens in Kruti Dev: government and court offices, print shops, DTP software like CorelDRAW and PageMaker, and many Hindi typing tests that follow the Remington layout (check your exam notice for the font and layout it allows). If your text was typed in Unicode but the file must be in Kruti Dev, you need a converter. This page does that in both directions.

Choose the right format

When should you use Unicode or Kruti Dev?

The best format depends on where the text will be read, edited and shared.

Use Unicode for

Text that needs to travel between devices

  • Web pages, email and messaging apps
  • Searchable documents and online forms
  • Phones, modern word processors and shared files

Unicode stores Hindi characters as text, so the recipient usually does not need a special legacy font just to read it.

Use Kruti Dev 010 for

Workflows that specifically require the legacy font

  • Older office or DTP documents
  • Print layouts built around Kruti Dev
  • Typing tasks whose instructions name Kruti Dev 010

Confirm the required font version first. Another legacy Hindi font may use different character mappings.

How it works

What the converter changes: real examples

Conversion is not a simple letter swap. Three things change the order and shape of the text.

  • The choti ee matra (ि) is typed before the consonant in Kruti Dev, but it comes after it in Unicode.
  • Reph (र्) sits on top of a letter, but in Kruti Dev it is typed after that letter as the key Z.
  • Half letters and conjuncts (like स्, क्ष, त्र, ज्ञ) have their own separate key codes.

Using the converted text in your software

  • MS Word and LibreOffice: paste, select all (Ctrl+A) and set the font to Kruti Dev 010. Keep English words in a normal font such as Times New Roman, otherwise they will also turn into Hindi shapes.
  • Excel: paste into the cell, then change the font of that cell or column from the Home tab.
  • CorelDRAW, PageMaker, Photoshop: paste into a text box and choose Kruti Dev 010 in the font list.
  • Google Docs and phones: Kruti Dev is not available there, so the text will stay as symbols. Use Word, LibreOffice or a desktop DTP tool instead.
  • Installing the font: copy the Kruti Dev 010 .ttf file, right-click it on Windows and choose Install. Download the font only from a source you trust and check its licence.

Common problems and quick fixes

  • I only see English letters: the Kruti Dev 010 font is not installed or not applied to that text.
  • Letters look wrong or matras are misplaced: another Kruti Dev version or a different Hindi font is applied. Switch to Kruti Dev 010.
  • English words turned into Hindi shapes: change only those words back to a normal font.
  • A rare conjunct looks odd: uncommon letter combinations can differ between fonts. Fix that letter by hand in your document.
  • Text copied from a PDF is garbled: PDFs often carry broken text. Retype a short sample here and compare.

A careful final check

Check these things before using converted text

A conversion can save retyping, but a quick review is still important for formal or print-ready work.

01

Convert two or three lines containing matras, half letters, names and punctuation before processing a long document.

02

Apply the matching font

03

Review names, dates and numbers

Compare the converted result with the source, especially for personal names, official terms, amounts and dates.

04

Keep an untouched source copy

Good practice: For court, government, exam or publishing work, follow the receiving office's format instructions and proofread the final document in the application that will open or print it.
