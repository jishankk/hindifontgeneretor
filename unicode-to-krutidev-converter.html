What is a Kruti Dev converter?

Kruti Dev is a family of older, non-Unicode Hindi fonts. It was built for the Remington-style typewriter keyboard and is still used in government offices, courts, newspaper and print layouts, and typing institutes. A legacy font like this does not store real Devanagari characters. It stores ordinary English keyboard characters and relies on the font to draw a Hindi shape for each one. That is why the word नमस्ते is saved as ueLrs and only looks like Hindi once Kruti Dev 010 is applied.

A Unicode to Kruti Dev converter turns normal Hindi text, the kind you type on a phone, in Google Docs or on a Windows keyboard, into those keyboard characters. It is more than a letter-for-letter swap. The short ि sign must move in front of its letter, the reph must move behind it, and joined letters such as क्ष and ज्ञ must be replaced by single ready-made glyphs. The converter above does these steps for you, as you type, and it also works in the other direction.

Four rules that cause most of the reordering

Kruti Dev follows the order in which a typist presses keys on a typewriter, not the order in which Unicode stores a syllable. Four rules explain nearly every difference you will see in the output.

  1. The short ि sign comes first. In Unicode it follows the consonant, but in Kruti Dev the key f is typed before the whole letter group. So हिन्दी becomes fgUnh, and स्थिति becomes fLFkfr because the sign sits in front of the entire joined letter स्थ.
  2. The reph (र्) comes last. It is drawn above a letter, but typed after that letter and its vowel sign as Z. So कार्य becomes dk;Z and धर्म becomes /keZ.
  3. Half letters have their own keys. A letter like स् has a separate half-form key (L). Letters that have no half shape in the font, such as ट, ड, द, ह, use a half key or a tilde, for example V~.
  4. Common joined letters are single glyphs. क्ष, त्र, ज्ञ, श्र, प्र, द्य and others are typed with one key instead of several, so the output is shorter than you might expect.

Why commas, full stops and slashes change

Many first-time users are surprised that a plain comma or a date like १५/०८/२०२६ looks different after conversion. The reason is the keyboard map. In Kruti Dev the comma key is used for the letter ए, the slash key for half ध and the full stop key for half ण. To still show a comma, a slash or a full stop, the font places them on other keys.

The converter applies this map by default, so punctuation looks right once the font is applied. If you only want the letters converted and plan to fix punctuation yourself, untick the punctuation option under the box.

Why Hindi work still uses Kruti Dev

Unicode is the modern standard and the right choice for writing, storing and sharing text. Kruti Dev has stayed in use for practical reasons:

  • Many government departments, courts, banks and print shops have templates, forms and old files built in Kruti Dev, and their staff are trained on the Remington-style keyboard that goes with it.
  • Several typing practice courses and Hindi typing tests are conducted in Kruti Dev. If you are preparing for one, check the exam notice for the exact font and keyboard layout, because some tests allow Inscript or another font instead.
  • Older design and publishing software, such as PageMaker and early versions of CorelDRAW, can display a legacy font even where it cannot shape Unicode Devanagari properly.
  • Clients usually send text in Unicode, so the designer or typist has to convert it to match the existing layout.

The trade-off is real. Kruti Dev text cannot be searched or spell-checked, screen readers cannot read it, it does not work on websites, and it turns into English symbols on any computer without the font. Treat it as a layout format, not a storage format, and always keep your Unicode original.

Which format should you use?

Use Unicode for

  • Websites, blogs, email and messaging apps
  • Google Docs, Sheets and online forms
  • Files you want to search or share on any device
  • Anything a search engine or screen reader should understand

Use Kruti Dev 010 for

  • Print layouts and templates already set in Kruti Dev
  • Office formats that name Kruti Dev 010
  • Typing practice and tests that specify it
  • Files that will be opened on a computer where the font is installed

Confirm the exact font name before converting. DevLys, Chanakya and other Kruti Dev versions use different key maps. If you only need to look up one letter or sign, the Hindi character map is quicker than converting a whole sentence.

Using the converted text in Word, Excel, CorelDRAW and other apps

  • MS Word and LibreOffice Writer: paste, select the text and set the font to Kruti Dev 010. Keep English words, English numbers and email addresses in a normal font, otherwise they turn into Hindi shapes too.
  • Excel: paste into the cell, then change the font of that cell, row or column. Sorting and filtering follow the Latin letters, not Hindi alphabetical order.
  • CorelDRAW, PageMaker, InDesign and Photoshop: pick the text tool, choose Kruti Dev 010 first, then paste. If the program asks how to paste, choose the option that drops the formatting of the source. Some layout programs re-map fonts when a file is opened on another machine, so keep the font installed there too.
  • Google Docs and phones: Kruti Dev is not available there, so the text stays as symbols. Do Kruti Dev work in Word or LibreOffice on a computer.
  • Installing the font: on Windows, right-click the font file and choose Install. Use font files only from a source you trust, and check the licence if the work is commercial.

Before you send a file to a press: the computer at the press may not have Kruti Dev. Embed the fonts when you export a PDF, or convert the text to curves or outlines, so the Hindi cannot turn into symbols on their side.

Converting Kruti Dev back to Unicode

Press the Kruti Dev to Unicode tab above the box, or the switch button below the output. The left box now expects Kruti Dev text and the right box shows Unicode. Paste the text exactly as it looks without the font, for example deZ, and not as the Hindi you see after applying the font.

  • Copy the text out of the original file as plain text first. Copying from a PDF often mixes characters up, so test a short line before trusting a long paste.
  • English words inside the same paragraph are also read as Kruti Dev and changed. Convert the Hindi parts separately if the document mixes both languages.
  • If the pasted text already shows proper Hindi, it is already Unicode and does not need converting.
  • The conversion follows the Kruti Dev 010 map. Text typed in Chanakya, DevLys or another family will come out wrong.
  • Proofread names, numbers and dates. They are the most expensive things to get wrong.

Common problems and quick fixes

  • I only see English letters: the Kruti Dev 010 font is not installed, or it is not applied to that text. Select the text and set the font again.
  • The ि sign or reph sits in the wrong place: another Kruti Dev version or a different Hindi font is applied. Switch to Kruti Dev 010.
  • English words turned into Hindi shapes: select just those words and change them back to a regular font.
  • Commas and slashes look odd: make sure the punctuation option was ticked when you converted, and that the whole text uses Kruti Dev 010.
  • A rare joined letter looks wrong: unusual combinations are built from half letters and can differ between fonts. Fix that one letter by hand in your document.
  • Text copied from a PDF looks garbled: PDFs often store Hindi in a broken order. Retype a short sample to compare.
  • The file looked right but is wrong on another computer: that computer does not have Kruti Dev 010. Install the font there, or send a PDF with fonts embedded.
  • I need to change a word: edit the Unicode text and convert again. Editing converted text by hand is easy to get wrong.

A short checklist for important documents

For court, government, exam or print work, follow the receiving office's format instructions and run through these four checks.

1. Test a small sample

Convert two or three lines with vowel signs, half letters, a name and some punctuation, and check them in your own software first.

2. Match the exact font

Use Kruti Dev 010. If an office asks for another version, a few glyphs can differ.

3. Re-read names, dates and amounts

Compare them with the source line by line. An automatic converter cannot know when a name is spelled unusually.

4. Keep the Unicode original

Save the source before replacing anything, so you can convert again if a mistake is found.

Frequently asked questions

How do I convert Unicode to Kruti Dev?

Type or paste your Hindi Unicode text into the box at the top of this page. The Kruti Dev text appears underneath at once. Press Copy, then paste it into Word, CorelDRAW or another desktop program and set the font to Kruti Dev 010.

Why does the converted text look like English letters and symbols?

That is how Kruti Dev works. It is a legacy font that stores ordinary keyboard characters and draws a Hindi shape in place of each one. Without the font installed and applied you only see the keyboard characters. Apply Kruti Dev 010 to the pasted text and the Hindi appears.

Which Kruti Dev font does this converter support?

It is built for Kruti Dev 010, the version most used in offices, courts, print shops and typing tests. Other versions such as Kruti Dev 011, 021 or 055 share most keys but can place a few glyphs differently, so check a sample line before converting a long document.

How do I convert Kruti Dev text back to Unicode?

Press the Kruti Dev to Unicode tab above the box, or the switch button. Then paste the text exactly as it looks without the font, for example deZ, and not as the Hindi you see after applying the font. The Unicode result can be used on websites, phones, Google Docs and messaging apps.

Why did my comma, full stop or slash change?

In Kruti Dev the punctuation keys are mapped differently. The comma key is used for the letter ए, so a comma is typed as ], a full stop as -, a hyphen as &, a slash as @ and the Hindi danda as A. The converter does this for you so that punctuation looks right once the font is applied. You can switch it off with the punctuation tick box if you only want the letters converted.

What happens to English words and numbers in the same paragraph?

Digits are written as ordinary 0-9, which Kruti Dev draws as English digits. English letters are copied unchanged, but Kruti Dev will draw them as Hindi shapes. Apply the Kruti Dev font only to the Hindi part, and keep English words, email addresses and web links in a normal font.

Can I convert Kruti Dev to Chanakya, DevLys or Shree Lipi?

Not in one step. Each legacy font has its own key map. Convert the text to Unicode first with this page, then convert the Unicode text to the other font. For Shree Lipi, use the Unicode to Shree Lipi converter on this site.

Can I use Kruti Dev text on a website or in Google Docs?

It is not recommended. Search engines and screen readers see the Latin letters, not Hindi, and visitors would need the font installed. Google Docs and most phones do not include Kruti Dev, so the text stays as symbols. Use Unicode for anything published online, and keep Kruti Dev for desktop publishing and office files that ask for it.

Does it work for Marathi text?

Common Devanagari letters convert the same way, so Marathi text mostly works. Marathi-specific letters such as ळ and some joined letters should be checked by hand after conversion. For Marathi print work, the Shree Lipi converter is often a better match.

Why is text I copied from a PDF converting badly?

PDFs often store Hindi in a broken order or with private font codes, so the text you copy is not clean Unicode. Convert a short line first. If the result looks wrong, retype that part or copy from the original Word or web source.

No. The conversion runs in your browser with JavaScript, and the text you type is not sent to or stored on this site's server.
