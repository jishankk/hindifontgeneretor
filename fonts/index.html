How the groups are organised

Fonts are grouped by how they look and what they are usually used for, not by quality. A stylish font is not better than a clean one; it is simply built for short, expressive text, while a clean font is built to be read for a long time. Many good designs use one of each: a stylish or bold font for the headline and a clean font for everything else.

Each group page opens the same generator, already filtered to that style. You can still switch groups from the tabs above the previews, search a font by name, or use the Best for shortcuts. If you want to see every font together, the home page shows all 61.
