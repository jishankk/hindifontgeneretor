Why these don't match a normal keyboard

Old Hindi fonts from before Unicode became widely used are Kruti Dev and AMS. Instead of using a standard phonetic layout, each key or code maps to a Hindi character inside the font itself; therefore, the mapping must be looked up rather than guessed.

Older government files, court documents, and DTP work from the 2000s still use these fonts. A font converter can convert a block of Kruti Dev or AMS text without requiring you to type it all at once.
