Before you start

How to read this chart

Kruti Dev is an older Hindi font. It stores no Hindi letters at all. What it stores is English characters, and the font draws a Hindi shape in place of each one. So the chart above is really a list of which English key the font turns into which Hindi shape. This chart follows the Kruti Dev 010 key positions, the version used by most offices, printers and typing institutes.

  • The key is what you type or paste. Apply the Kruti Dev 010 font to it and the Hindi appears. In a normal font you only see the key.
  • Some letters need two characters. ख is [k, ध is /k, भ is Hk. The second k completes the letter, and the first part alone gives the half letter.
  • Capitals and lower case are different keys. Check the case of every character before you copy.
  • Special characters are real characters. Keys like Å, ³ and Ø come from the Latin-1 set. On a Remington layout they have their own keys, otherwise use the Alt code shown on the card.

This is a chart for Kruti Dev 010 only. DevLys, Chanakya and Kruti Dev 055 share many keys but not all of them, so do not use this chart to type in those fonts without testing a few letters first.

The logic behind the keys

Four patterns that explain most Hindi words

Learn these and you can read almost any Kruti Dev text, because the chart above only covers the individual pieces.

Pattern 1

The choti ee matra goes first

In Hindi the ि sign is written before the letter but pronounced after it. Kruti Dev follows the written order: type f first, then the consonant.

कि = fd
हिन्दी = fgUnh
Pattern 2

Reph goes last

The र् that sits on top of a letter is typed after the letter it belongs to, as Z. In a conjunct, it goes after the whole syllable.

कर्म = deZ
धर्म = /keZ
Pattern 3

Half letters join to the next letter

To write a conjunct, type the half form and then the full letter. The half form is usually the key without its trailing k.

सत्य = lR;
स्वतंत्र = Lora=
Pattern 4

The ्र sign is its own key

The small ्र that hangs under a letter, as in प्र or क्र, is the key z. It attaches to the letter typed before it.

प्रेम = izse
ग्रह = xzg

Frequently asked questions

Why does Kruti Dev show English letters instead of Hindi?
Because the file holds English characters and the font draws Hindi shapes over them. Without the Kruti Dev 010 font applied, the same characters show as plain English letters.
Is the Kruti Dev keyboard the same as the Hindi Remington layout?
They are closely linked. Kruti Dev text is normally typed on a Remington style layout, where each Hindi letter sits on a fixed key. This chart lists the character each key produces rather than the physical layout, so you can use it with any keyboard.
How do I type a character like Å or ³ if it is not on my keyboard?
On Windows, hold Alt and type its four digit code on the numeric keypad. The card for each such character shows the code. You can also copy the key from the card and paste it straight into your document.
Does this chart work for Chanakya, DevLys or Kruti Dev 055?
Not reliably. These fonts share many keys with Kruti Dev 010 but differ for some letters, mostly conjuncts and special signs. Test a short word before using this chart for another font.
Why are capital and small letters different?
They are different keys with different Hindi shapes. For example d is क and D is the half letter क्. Always check the case before you copy a key.
Can I use this chart to read old Kruti Dev text?
Yes. Search for a character you see in the old text and the card tells you which Hindi letter it stands for. For a whole file it is faster to paste it into the converter and switch it to Kruti Dev to Unicode.
