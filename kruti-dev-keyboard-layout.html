What is the Kruti Dev keyboard layout?

Kruti Dev is a font-based way of typing Hindi. Instead of a Hindi keyboard, you use your ordinary English keyboard, and the font draws a Hindi shape for every key. The pattern of which key gives which letter is the Kruti Dev keyboard layout. It is widely taught in Hindi typing institutes and used for office work, court documents and print layouts, and it is closely related to the Remington typewriter pattern that many typists already know.

The chart above shows the layout of Kruti Dev 010. The large Hindi character on each key is what you get by pressing the key alone. The small green character on top is what you get when you hold Shift. Press a key on your keyboard while the practice box is focused and the matching key lights up.

The chart is generated from the same key tables that power the Unicode to Kruti Dev converter, so what you see here matches what the converter produces. Signs that attach to other letters, such as ा, ि, ्र, are shown with a dotted circle.

How to read the chart

Four ideas explain most of the layout:

  • Most letters have a full and a half form. The key alone usually gives the full letter, for example d gives क. The Shift version gives the half form, for example D gives क्, which you use when the letter joins to the next one, as in पक्का.
  • Some letters need two keys. The font draws certain letters, such as ख, घ, थ, ध, भ, श, ष, as a half form plus the vertical bar. To type थ you press F and then k.
  • Vowel signs are on the home and top rows. k is ा, h is ी, q is ु, w is ू, s is े and S is ै.
  • Two signs break the reading order. The key f (ि) is pressed before the letter, and the Shift+Z key (reph) is pressed after the letter. This is the biggest difference from Unicode typing.

A few ready-made glyphs that the converter produces, such as ç for प्र, are not on the keyboard. On a keyboard you get the same look by typing the letter and then z, so प्र is iz.

How to start typing in Kruti Dev

  1. Install Kruti Dev 010 from a source you trust and check its licence terms if the work is commercial. On Windows, right-click the font file and choose Install.
  2. Open Word, LibreOffice Writer, CorelDRAW or another desktop program and choose Kruti Dev 010 as the font before you type. Web pages and most phone apps will not show the Hindi shapes, because they do not use the installed font for your text.
  3. Keep your keyboard on English. Turn off Caps Lock, because capital letters give half forms and other letters.
  4. Learn the home row first. The keys a s d f g h j k l ; hold ं, े, क, ि, ह, ी, र, ा, स, य, which are among the most used signs and letters.
  5. Practice whole words, not single keys. Use the practice box above, start with short words and work towards sentences.
  6. Keep English words and numbers in a normal font. With Kruti Dev selected, English letters turn into Hindi shapes.

If you already have Unicode Hindi text and do not want to retype it, paste it into the Unicode to Kruti Dev converter. For a single sign or letter, the Hindi character map is quicker.

Tips for typing tests and office work

  • Confirm the layout and font first. Exam and office notices name the font (Kruti Dev 010 is common) and sometimes the exact layout variant. Practice on the one that is named.
  • Know the key order, not just the shapes. Some Hindi tests count key presses rather than words, so a half letter or a vowel sign is a separate press. Typing क्ष as one key instead of three saves presses.
  • Type the reph last. Beginners often press Shift+Z too early. Finish the letter and its vowel sign first, then add the reph.
  • Watch the font when you proofread. If a line looks strange, check that Kruti Dev 010 is applied to the whole line and not a different Hindi font.
  • Do not mix English and Kruti Dev in one font setting. Switch the font for English words, then switch back.
  • Save a Unicode copy. Keep your final text in Unicode as well, so you can reuse it on the web or on a phone later.

Common typing mistakes and fixes

  • The ि sign appears after the letter: you pressed f after the letter. Press it before the letter or letter group.
  • The reph lands on the wrong letter: press Shift+Z right after the letter that should carry it, and after that letter’s vowel sign.
  • You get a half letter where you wanted a full one: Caps Lock is on, or you held Shift. Release Shift, and press the next key to complete the letter, for example F then k for थ.
  • Everything shows as English letters: the Kruti Dev font is not applied. Select the text and choose Kruti Dev 010.
  • Brackets, commas or slashes look wrong: in Kruti Dev these keys produce Hindi letters. The comma key gives ए, the slash key gives half ध, and ordinary punctuation sits on other keys. The converter page lists them.
  • A word looks wrong on another computer: that computer does not have Kruti Dev 010. Install it or send a PDF with embedded fonts.

Frequently asked questions

What is the Kruti Dev keyboard layout?

It is the key map that comes with Kruti Dev fonts. Each key of an ordinary English keyboard is assigned a Hindi letter, vowel sign or half letter, so you type Hindi with the same keyboard you use for English. With Kruti Dev 010 selected, pressing d gives क, k gives ा and f gives ि.

Is the Kruti Dev layout the same as the Remington layout?

Kruti Dev is commonly described as following the Remington typewriter pattern, and that is how many typing institutes teach it. Some exams name a specific variant such as Remington Gail or Remington CBI, and a few keys can differ between variants. Check the notice for your exam and practice on the exact layout it names.

Can I type in Kruti Dev on a normal English keyboard?

Yes. You do not need a special keyboard. Install the Kruti Dev 010 font, select it in Word or another editor, and type the keys shown in the chart. The Hindi shapes appear because the font draws them in place of the English letters.

Why do I press the key for ि before the letter?

Kruti Dev follows the order of a typewriter, where the sign is placed first and the letter is struck after it. So हिन्दी is typed f, g, U, n, h. Unicode keyboards store the sign after the letter instead.

How do I type the reph?

Type the letter (and any vowel sign) first, then press Shift+Z. The reph is drawn above the letter you typed just before it. For example कर्म is typed d, e, Z.

How do I type क्ष, त्र, ज्ञ and श्र?

क्ष is the { key followed by k, त्र is the = key, ज्ञ is Shift+K and श्र is Shift+J.

Why are some glyphs from the converter, such as ç or Ø, not in the chart?

A few ready-made joined letters sit on keys that need Alt codes. On a keyboard you get the same result by typing the letter and then z for the ्र sign, for example i then z for प्र. The converter on this site uses the single glyph, and the two look the same once Kruti Dev 010 is applied.

Is Kruti Dev the same as Inscript?

No. Inscript is the standard Unicode layout, where each key has a fixed Devanagari character and the text is stored as real Hindi. Kruti Dev is a font-based layout, so the text is stored as English letters and only looks like Hindi with the font. The key positions are also different.

Can I use the practice box to get Unicode text?

Yes. As you type Kruti Dev keys, the box underneath shows the matching Hindi Unicode text, which you can copy and use on websites, phones and Google Docs. For larger texts, use the converter instead of typing.

Does the chart cover Kruti Dev 011, 021 or 055?

The chart follows Kruti Dev 010. Other versions share most keys, but a few glyphs and signs can sit on different keys, so check a sample if you use a different version.
